## ✨ Features

- **Login System:** Secure login with validation
    - Email: `admin@campus.com`
    - Password: `123456`
- **Dashboard:** Shows Total Students, Total Fees Collected, Total Courses
- **Manage Students:** Add, Edit, Delete Students
- **Form Validation:** Shows RED error if Name / Email / Course / Fees is empty or wrong
- **Search:** Search student by Name / Course instantly
- **localStorage:** Data stays saved even after page Refresh / Browser Close
- **Responsive Design:** Works on Laptop + Mobile
